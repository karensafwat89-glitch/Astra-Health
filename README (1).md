# ASTRA HEALTH Datasets

This folder contains datasets for the three health monitoring modules:

1. Cardiovascular data
2. Sleep and fatigue data
3. Radiation exposure data

## Current Data Status

All currently included CSV records are simulated data.

They are created for software development, testing, and demonstration purposes.

No real astronaut medical records or NASA datasets are currently included.

## Future Data Sources

NASA Open Science Data Repository (OSDR) may be explored as a potential source of relevant research datasets.

Any future real datasets will be clearly identified and documented.

## Data Integrity

- Simulated data must be labelled as SIMULATED.
- Real data must have a documented source.
- Missing or invalid measurements must not be treated as normal.
